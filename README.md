# Nora Fan — GitHub Pages portfolio

This folder contains a bilingual personal platform using Nora's pink, blue, red and peach palette. It needs no build step and can be published directly with GitHub Pages.

Pages included:

- `index.html` — platform homepage
- `academic.html` — research, education and academic CV
- `experience.html` — campus leadership and volunteer projects
- `life.html` — personal notes, reading, culture and places
- `about.html` — profile, working principles and contact

## Publish

1. Upload all HTML files, `style.css`, and `script.js` to the root of your `username.github.io` repository.
2. In GitHub, open **Settings → Pages** and choose **Deploy from a branch**, `main`, `/ (root)`.
3. Wait a few minutes, then visit `https://username.github.io`.

## Replace before publishing

The contact links, public profile and bilingual content are already filled in. One optional item remains:
